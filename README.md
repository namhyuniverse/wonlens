# wonlens

바이낸스 화면의 USDT 금액(마진 밸런스·자산·PNL 등) 옆에 **업비트 USDT/KRW 실시간 체결가**로 환산한 원화 값을 붙여 주는 크롬 확장.

```
Margin Balance   1,234.56 USDT ≈ ₩1,683,940      (나란히 · 원)
Unrealized PNL     -12.30 USDT ≈ -1.7만원        (나란히 · 만원)
Margin Balance   168.4만원                        (원화만)
```

## 설치

1. `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
3. 바이낸스 탭 새로고침

코드를 고친 뒤에는 확장 카드의 새로고침 버튼을 누르고 바이낸스 탭도 새로고침한다.

## 팝업

| 항목 | 내용 |
| --- | --- |
| 스위치 | 원화 표시 켜기/끄기. 단축키 `Alt+Shift+K`, 켜져 있으면 아이콘에 `₩` 배지 |
| 시세 | 업비트 USDT/KRW 체결가와 체결 시각. 초록 점이면 웹소켓 실시간, 회색이면 REST |
| 김프 | 업비트 USDT 원화 시세가 ECB USD/KRW 기준환율(전 영업일)보다 몇 % 비싼지 |
| 표기 | `₩ 원`(₩1,683,940) · `만원`(168.4만원) · `자동`(1만 미만 ₩, 1억 미만 만원, 그 위 억원) |
| 보기 | `나란히`(USDT 옆에 원화) · `원화만`(USDT 숫자를 숨기고 원화만 같은 크기로) |
| 칸 직접 지정 | 자동으로 못 잡는 칸을 바이낸스 화면에서 클릭해 지정. 지정한 칸을 다시 누르면 해제, Esc 취소 |

## 동작 방식

- **시세**: `src/background.js` 가 업비트 웹소켓(`wss://api.upbit.com/websocket/v1`, `KRW-USDT` ticker)을 연다. 바이낸스 탭이나 팝업이
  열려 있는 동안만 연결하고, 마지막 탭이 닫히면 30초 뒤 닫는다. 20초마다 PING 을 보내 연결과 서비스 워커를 살려 두고, 30초 넘게
  체결이 없거나 연결이 끊기면 REST(`/v1/ticker`)로 한 번 받는다. 탭에는 최대 0.5초에 한 번 보낸다. 안 보이는 탭은 연결을 끊는다.
- **김프 환율**: ECB 유로 기준환율로 계산한 USD/KRW([frankfurter](https://frankfurter.dev), 영업일 하루 한 번)를 쓴다. 1시간
  캐시. 팝업에 출처(ECB)와 기준일을 같이 보여 준다. 장중 환율이 아니라서 김프는 전 영업일 기준 어림값이다.
- **금액 찾기**: `src/content.js` 가 화면의 텍스트를 훑는다.
  - `1,234.56 USDT`·`-12.3 USDT (-5%)`·`$1,234.56`·`≈ $98.7` 처럼 USDT·USDC·FDUSD·`$` 가 붙은 짧은 텍스트(48자 이하)
  - 숫자와 단위가 다른 태그로 나뉜 경우(`<span>-12.3</span><span>USDT</span>`)는 2단계 위 조상까지 올라가 같은 금액인지 확인한다
  - 직접 지정한 칸은 단위가 없어도 USD 로 본다. 화면 종류(경로 첫 칸: `futures`, `my` 등)별로 CSS 경로를 저장한다
- **그리기**: 찾은 요소에 `data-wonlens*` 속성만 달고 CSS `::after` 로 원화를 그린다. 바이낸스 DOM 텍스트를 고치지 않아 React
  렌더링과 부딪히지 않고, 끄면 속성과 스타일을 지워 흔적이 남지 않는다. 화면이 바뀌면(`MutationObserver`) 바뀐 부분만 200ms
  묶음으로 다시 본다.

## 한계

- 단위 없이 숫자만 있는 칸(표 헤더에만 `(USDT)` 가 있는 경우)은 자동으로 잡지 않는다. 가격·호가가 원화로 잘못 바뀌는 걸 막으려는
  의도다. 필요한 칸은 직접 지정한다.
- 직접 지정은 요소 위치(CSS 경로)로 기억한다. 포지션 표처럼 행 순서가 바뀌는 곳에 지정하면 다른 행을 가리킬 수 있고, 바이낸스가
  화면 구조를 바꾸면 지정이 풀린다. 계정 요약처럼 자리가 고정된 칸에 쓴다.
- `1.23K USDT` 같은 축약 표기, BTC 등 코인 단위 금액은 바꾸지 않는다.
- `$` 금액도 USDT 와 같다고 보고 업비트 USDT 시세를 곱한다(테더 김프가 그대로 들어간다).
- 시세를 10분 넘게 못 받으면 원화 표시를 비우고 원래 숫자를 보여 준다.
- `원화만` 은 원래 글자 크기를 재서 쓴다(Chrome 133+ 의 `attr()` 타입 지원). 그보다 낮은 버전은 13px 로 그린다.
- 칸 폭이 좁고 `overflow: hidden` 인 곳은 원화가 잘릴 수 있다.

## 비용·개인정보

- 업비트 시세(REST·웹소켓)는 공개 API 라 무료이고 키·계정이 필요 없다. 각 사용자의 브라우저가 직접 조회하며, 업비트 개발자 센터의
  요청 수 제한 안에서만 쓴다.
- ECB 기준환율도 키 없이 쓴다.
- 바이낸스 화면은 브라우저 안에서만 읽는다. 밖으로 나가는 요청은 위 시세·환율 조회뿐이고, 바이낸스 계정·잔고 값은 어디에도 보내지
  않으며 아무것도 수집·저장하지 않는다(설정만 브라우저 `chrome.storage` 에 둔다).

## 고지

- **비공식 도구다.** Binance·Upbit(두나무)·ECB 와 제휴하거나 승인받지 않았다. 각 이름과 상표는 해당 회사의 것이고, 어떤 화면에서
  동작하는지 설명하는 데만 쓴다.
- **데이터 출처**: USDT/KRW 시세는 업비트 Open API(저작권 두나무), USD/KRW 는 European Central Bank 기준환율이다. 표시되는 원화는
  두 값으로 계산한 어림값이고 정확성·실시간성을 보증하지 않는다.
- **유상 배포 금지**: 업비트 Open API 이용약관 제6조 3항은 Open API 를 이용하는 프로그램을 타인에게 유상으로 양도·배포·이용 허락하는
  것을 금지한다. 코드 라이선스(MIT)와 별개로, 이 프로그램이나 수정본을 돈을 받고 팔거나 유료 서비스에 넣지 말 것.
- **바이낸스 이용약관**: 바이낸스 약관은 자동화 도구·스크립트 사용을 제한한다. 이 확장은 주문·클릭 등 어떤 동작도 자동으로 하지 않고
  보이는 화면에 표시만 덧붙이지만, 제3자 확장 사용이 약관에 맞는지는 사용자가 판단하고 책임진다.
- **투자 조언이 아니다.** 환산값·김프는 참고용 숫자이고, 이를 근거로 한 거래 결과에 대해 작성자는 책임지지 않는다(MIT 라이선스의
  무보증 조항 참고).

## 테스트

```
npm install
npm test
```

`test/format.test.js` 는 금액 판별·원화 표기·김프 계산, `test/content.test.js` 는 jsdom 의 바이낸스 비슷한 화면에서 표시·갱신·
단위·원화만 보기·끄기·직접 지정을 확인한다. 실제 바이낸스 화면과 웹소켓 연결은 브라우저에서 확인해야 한다.
