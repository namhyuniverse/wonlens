# wonlens

바이낸스 화면의 USDT 금액 옆에 **원화 환산값**을 붙여 주는 크롬 확장입니다.
환율은 업비트 USDT/KRW 실시간 체결가를 씁니다.

```
Margin Balance   1,234.56 USDT ≈ ₩1,683,940
Unrealized PNL     -12.30 USDT ≈ -1.7만원
```

## 기능

- **실시간 환산**: 업비트 USDT/KRW 체결가를 웹소켓으로 받아 바로 반영
- **김프 표시**: 업비트 USDT 시세가 USD/KRW 기준환율보다 몇 % 높은지
- **표기 단위**: `₩1,683,940` · `168.4만원` · 자동(만·억)
- **원화만 보기**: USDT 숫자를 숨기고 원화만 표시
- **칸 직접 지정**: 자동으로 안 잡히는 칸을 클릭해서 지정
- **켜기/끄기**: 팝업 스위치 또는 `Alt+Shift+K`

## 설치

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP` 후 압축 해제, 또는 `git clone`)
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 내려받은 폴더 선택
4. 바이낸스 탭을 새로고침

크롬 116 이상이 필요합니다.

## 사용법

툴바의 wonlens 아이콘을 누르면 팝업이 열립니다.

| 항목 | 설명 |
| --- | --- |
| 스위치 | 원화 표시 켜기/끄기. 켜져 있으면 아이콘에 `₩` 배지 |
| 시세 | 지금 쓰는 환율과 체결 시각. 초록 점이면 실시간 연결 중 |
| 김프 | 업비트 USDT 시세와 ECB 기준환율(전 영업일)의 차이 |
| 표기 | `₩ 원` · `만원` · `자동` |
| 보기 | `나란히`(USDT 옆에 원화) · `원화만` |
| 칸 직접 지정 | 버튼을 누른 뒤 바이낸스 화면에서 숫자 칸 클릭. 지정한 칸을 다시 누르면 해제, `Esc` 취소 |

## 어떤 금액이 바뀌나요

`1,234.56 USDT`, `-12.3 USDT`, `$1,234.56` 처럼 **USDT·USDC·FDUSD·$ 단위가 붙은 금액**만 자동으로 바꿉니다.

- 가격·호가처럼 단위 없이 숫자만 있는 칸은 바꾸지 않습니다. 필요하면 직접 지정하세요.
- BTC 등 코인 단위 금액과 `1.23K` 같은 축약 표기는 바꾸지 않습니다.
- `$` 금액도 USDT 와 같다고 보고 계산합니다.
- 환율을 10분 넘게 받지 못하면 원화 표시를 숨깁니다.

직접 지정한 칸은 화면 위치로 기억하므로, 포지션 표처럼 행 순서가 바뀌는 곳보다 계정 요약처럼 고정된 칸에 쓰는 것이 좋습니다.

## 개인정보

- 바이낸스 화면은 브라우저 안에서만 읽고, 계정·잔고 정보를 어디에도 보내거나 저장하지 않습니다.
- 외부 요청은 업비트 시세 조회와 ECB 기준환율 조회뿐입니다. 둘 다 키나 로그인이 필요 없습니다.
- 설정(켜기/끄기, 단위, 지정한 칸)만 브라우저에 저장합니다.

## 고지

- **비공식 도구입니다.** Binance, Upbit(두나무), ECB 와 관계가 없으며 승인받지 않았습니다. 각 이름과 상표는 해당 회사의 것입니다.
- **데이터 출처**: USDT/KRW 시세는 업비트 Open API(저작권 두나무), USD/KRW 는 European Central Bank 기준환율입니다.
  표시되는 원화는 어림값이며 정확성을 보증하지 않습니다.
- **유료 판매 금지**: 업비트 Open API 이용약관(제6조 3항)은 Open API 를 쓰는 프로그램의 유상 양도·배포를 금지합니다.
  코드 라이선스와 별개로 이 프로그램이나 수정본을 판매하거나 유료 서비스에 포함하지 마세요.
- **바이낸스 이용약관**: 이 확장은 주문·클릭 같은 동작을 하지 않고 화면에 표시만 덧붙입니다. 다만 제3자 확장 사용이
  바이낸스 약관에 맞는지는 사용자가 판단해야 합니다.
- **투자 조언이 아닙니다.** 표시되는 숫자를 근거로 한 거래 결과에 대해 책임지지 않습니다.

## 개발

```
npm install
npm test
```

| 경로 | 역할 |
| --- | --- |
| `src/background.js` | 업비트 웹소켓·REST 시세, ECB 기준환율 |
| `src/content.js` | 바이낸스 화면에서 금액 찾기·원화 표시·칸 지정 |
| `src/format.js` | 금액 판별, 원화 표기, 김프 계산 |
| `popup/` | 설정 팝업 |

원화는 바이낸스 화면의 글자를 바꾸지 않고 CSS 로 덧붙여 그리기 때문에, 끄면 흔적 없이 사라집니다.
